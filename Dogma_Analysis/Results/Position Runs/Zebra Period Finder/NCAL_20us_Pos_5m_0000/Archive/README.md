# Technical archive - not final results

For normal result browsing, return to the [five final step folders](../README.md).
Nothing in this archive is another 5 m acquisition.

- **Processing history:** small pilots, the rejected original clock fit,
  backend tables, settings and execution logs in their historical layout.
- **Reports:** original-run comparisons, regression logs and run-level QC.
- **Run scripts:** frozen copies of the padiwa launchers, verifiers and
  transfer helpers. They retain their original remote-layout assumptions
  and must not be run from this relocated local archive.
- **Provenance:** the original copy records and reports, the current
  remote-to-local path mapping and current SHA-256 inventory.
- **Other files:** preserved filesystem metadata.

No analysis was rerun or changed for this reorganization. The remote layout
is unchanged. All 1,573 copied source artifacts retain their original bytes;
updated local browsing documents are recorded separately in the current
[manifest](Provenance/COPY_MANIFEST.json).
